# 决赛圈对打 + 方案 A 口径对照（2026-11-15 收尾）

本文件回答两个问题，全部用**同一把尺**（`ptcg_league/eval_pair.py`，Bo3、座位交替）量：

1. 五个候选驾驶员里谁是第一 —— 决赛圈循环赛（双向、每向 600 场）。
2. "训练到底有没有用" —— **同一副牌、同一套对手，只换驾驶员**，在方案 A 测试集上的加权胜率差。

## 3. 本轮修掉的坑（都已固化进工具）

1. **方案 A 的证据进不了母表**：`export_master.py` 剥种子后缀得到 `candf5f8S_A`，`TAG2CELL` 查不到就丢弃
   ⇒ 300 条方案 A 证据一条都没进母表，行级"最佳驾驶员"一直停在 init。已改为"查不到就脱 `_A` 再查"，
   并补登 `candf5f8S / cand26c6S / cand26c6M / r1A*` 与新的强对手格。
2. **拉取必须校验**：`collect_eval.sh` 用 `rsync --ignore-existing` 会把正在写的半截 JSON 拷进来且**永不补**。
   新增 `tools/pull_results.sh`：先落到临时目录、逐文件试解析、通过才落地（同名但样本更小的会被替换）。
   本轮靠它把两台被释放机器上的结果全部抢下来了。
3. **机器会被中途释放**：139.218、1.92.97.36 分别在 22:10、22:46 掉线。丢的只有
   `r1A` 的两对方向 与 `port_2617_A` 的 4 格（后者把已拉回的 8 格推到 A 机，只补了 4 格即完成）。
   ⇒ 长期跑机一律配 `tools/watch_and_snapshot.sh`（定时 拉取→刷表→git 提交）。
4. **提交包与本地证据的一致性**：`ptcg_sub_candf5f8S.tar.gz` / `cand7e39S.tar.gz` 里的 `model.pt` md5

## 5. 2026-11-16 补短板实验：`candf5f8G`（2617 / 3eaa 两格专项陪练）

**动机**：方案 A 上 f5f8 行只有两格明显低于端口基线——`grookey_2617`（权重 0.117，−14.0pp）
和 `dreepy_3eaa`（权重 0.036，−12.7pp），合计约 15% 场地权重。

**配置**（唯一变量 = 陪练池；起点 `INIT=/root/kl/candf5f8S.bin`）：8 个 bank 各 6.25%（冻结对手共 50%），
其中 **3 个绑 2617**（人类 BC 克隆 `deck_2617_grookey`、`ph3_2617_v1`、端口权重）、
**2 个绑 3eaa**（端口权重、`ph3_2617_v1` 换牌）、`g8_bc_parent`@0d86 守格、`deck_f5f8_`@f5f8 镜像、`r1A`@26c6 防遗忘；
4M 步 / 43 min / 3090（SPS 1534，显存 19.1 G，8 bank 需 `CG=1`）。
训练中对手行里有 **19% 是 2617 牌、13% 是 3eaa 牌**（设计 18.75% / 12.5%），三项训练健康指标正常
（`enverr 0`、`ill 0`、`kl 0.0026`）。

**结果（n=600/格，3 种子；B0 = candf5f8S）**

| 判据 | B0 | candf5f8G | Δ | 门槛 | |
|---|---|---|---|---|---|
| G1 vs `c_grookey`（端口@2617，面板格） | 46.0% | **54.2%** | **+8.2pp** | ≥+5 | ✓ |
| G2 vs `ph3_2617_v1`（最强 2617 驾驶员） | 42.5% | **47.7%** | **+5.2pp** | ≥+5 | ✓ |
| G3 vs `opp_3eaa`（端口@3eaa，面板格） | 33.5% | 35.5% | +2.0pp | ≥+5 | ✗ |
| G5 vs `g8_bc_parent`（守 0d86 格） | 90.0% | 90.0% | 0.0 | ≥89% | ✓ |
| G4 方案 A 面板（n=450） | 61.3% | **62.7%** | +1.4pp | 降≤2pp | ✓ |
| 直接对打 vs `candf5f8S` | — | **52.7%** | +2.7pp | — | 略优，不显著（±4pp） |

逐格（方案A，f5f8G − f5f8S，单种子 n=150，噪声 ±7pp，只作方向参考）：
`dreepy_3eaa` +6.7、`grookey_2617` +2.4、`dunsparce_db04` +2.4、`champ_0904` +4.4、
`abra_f5f8` +0.4、`dunsparce_0bf5` +0.9；

**结论**
- **2617 这一格修好了**：面板格 +8.2pp、对强驾驶员 +5.2pp，是这次唯一达到预注册门槛的目标。
- **3eaa 没修好**（+2.0pp）：给它 25% 的对手行、学习者仍输 81–90%，4M 步推不动。
  该格更像**卡组级克制**（端口权重开 3eaa 的行级分 42.6% 就比我们 38.7% 高），下一轮若还做，需要把 3eaa bank 加到 4/8 且延长到 6M+ 步，或换打法轴（不要只加陪练量）。
- **整体略优但不显著**：面板 +1.4pp、H2H 52.7%。按预注册判据（全过才算候选）**未全过**，
  所以 `candf5f8G` 先登记为**候补驾驶员 + 2617 格的强陪练 bank**，不单独替代 `candf5f8S` 的提交位。
