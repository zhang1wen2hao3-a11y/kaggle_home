# 下一步实验计划（2026-11-13，A/B 四轮之后）

> 起点：`docs/ab_run2.md`（四轮产物与面板）、`models/weights/ab/MANIFEST.md`（权重协议）、
> `docs/the-pockmon-battle-choices-win-rate.csv`（132 格 a→b 胜率，已标定）。

## 0. 先给结论：A/B 这条线到此为止

四条独立证据：

| 证据 | 数据 |
|---|---|
| 四份权重与基线在 n=200 下**不可区分** | 加权 Δ：r1A +2.4pp `[-1.0,+5.9]`、r2A +0.2pp `[-3.6,+4.0]`、r1B −0.5pp `[-4.1,+3.3]`，CI 全跨 0 |
| 逐格也没有信号 | r1A 12 格里仅 1 格名义显著（`abra_f5f8 +13.5pp`，CI `[+3.9,+22.7]`），12 次检验下这是噪声期望值；Bonferroni 后**0 格**显著。r2A 2 格、r1B 0 格 |
| 位移大 ≠ 更好 | r2A 位移 3.12%（r1A 的 1.75 倍），面板却回落到基线 (+0.2pp) |
| 训练期胜率与离线面板解耦 | A 阶段训练 Δ≈0（r1A）→ 面板 +2.4pp；B 阶段 Δ≈0 → 面板 −0.5pp。**方向都不保证** |

换边机制本身没有问题（timebox ×2、增益触发 ×2，四条路径都有真机日志，见 `ab_run2.md` §7）。
所以该停的不是"机制"，是"在 4M 步/侧的预算下靠交替换对手来提升"这条路。

## 1. 优先级 1：对手权重按"改进空间"加权（只改一个文件，其余不动）

**依据**：现在的 `weights_field_b05.txt` 是纯天梯覆盖率，但
`7e39` 占 28.6% 而我们已 0.875（近上限，白花算力）；
`2617` 只占 9.6% 而我们 0.420（最大漏分格）；
`0d86` 占 9.7% 而我们 0.980（几乎白送）。

**现成产物**：`decks/weights_9d6e_mix50.txt`（α=0.5 混合，36 副总和 1.0，
7e39 28.6%→20.6%、2617 9.6%→14.7%、0d86 9.7%→5.2%）。

```bash
DWF=decks/weights_9d6e_mix50.txt INIT=/root/kl/port_w.bin T=4000000 \
  ANCHOR=dunsparce_abra__9d6e TRACK=dunsparce_abra__9d6e LEAGUE_PCT=1.0 \
  BANKS=/root/kl/port_w.bin bash tools/db04_line.sh
```

**预注册判定**（先写死，避免事后解释）：
- 12 格面板 n=200 × **3 个种子合并**（950000/950001/950002），对照 `meta_port_9d6e` 同种子；
- **有效**：加权 Δ ≥ +3pp 且 95% CI 下界 > 0；
- **无效**：Δ < +3pp 或 CI 跨 0 ⇒ 这条也放弃，转优先级 2。

**成本**：4M 步 ≈ 40 分钟（4080S @1700 SPS）+ 3 个面板种子 ≈ 70 分钟（32 核机）。

## 2. 优先级 2：把舰牌换回 `db04`

**依据**（`tools/deck_field_matrix.py`，已用面板标定：db04 行 0.7260 vs 面板 0.7261）：

| 舰牌 | 场地加权期望胜率 |
|---|---|
| **db04** | **0.7260**（我们面板实测 `g6_db04@db04` = **0.7261**，全场最高） |
| 9d6e | 0.7184（面板 0.6842） |
| 26c6 | 0.3421 ← 冠军牌但当舰牌是陷阱（7e39 上仅 0.12） |
| 0d86 | 0.3308 ← 同上（7e39 上 0.24） |

`db04` 的短板更集中（`2617` 0.57），比 `9d6e`（`2617` 0.42）好补。

**判定**：与现有 `g6_db04@db04` 面板 0.7261 对照，Δ ≥ +2pp 且 CI 下界 > 0 才算新进展。

## 3. 优先级 3：拿 LB 当裁判（每天都该做，不占算力）

每天 2 次提交、取最高。已有面板排序：`g6_db04@db04` 0.7261 > `r1A@9d6e` 0.7066 ≈ `端口@9d6e` 0.6842。
面板与 LB 的历史一致性：db04 1060.3、9d6e 992.1（面板高一档，LB 也高一档）。
⇒ 提交位优先给面板最高的那个，除非优先级 1/2 出现了过门槛的候选。

## 4. 负面清单（别再做）

| 不做 | 原因 |
|---|---|
| 加轮次（6–8 轮）或加到 10M/50M 步 | 4M→10M 的水位结论：位移线性涨、胜率不涨 |
| 按格给 9d6e 路由不同驾驶员 | 四份权重与 port 不可区分，按格取 max = 系统性挑噪声（choice 表的 5pp 阈值也挡不住 n=200 的 ±6.5pp） |
| 用训练期 `lgw`/Δ 做任何决策 | 与离线面板两次反向（r1A 面板好但训练 Δ≈0；r1B 训练平但面板差） |
| 用 `state_*.bin` 当权重 | 含优化器状态，import 会 assert |
